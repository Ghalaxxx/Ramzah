## Checkpoint compatibility and honest evaluation

`ramzah/cv.py` reconstructs the downloaded checkpoint using BART **visual coordinate** layers, x/y projections and an isolated-sign head. This is not an NLP stage. All tensors load strictly. The legacy config contains contradictory `num_hidden_layers=6` and `encoder_layers=2`; the weights have two layers, so the alias is removed. A successful tensor load does not prove equivalence to the original unpublished extraction/training run.

The first real downloaded 15-frame sequence, mapped to class 0001, produced 0002 at 0.3264. See `evidence/baseline_smoke.json`. This failed example is retained. Frames were remuxed at assumed 30 FPS solely for a pipeline smoke test; native timing is not established by that MP4. We cannot reproduce the card's 99.36% benchmark from its incomplete documentation.

Adapt the classifier to verified labels using fresh Holistic Tasks extraction. Select checkpoints on validation loss; fit temperature and a confidence threshold on validation only; never optimize them on test. The threshold requires at least 20 accepted validation observations with Wilson 95% lower precision bound >=0.80. If no threshold qualifies, all results require review. Even a qualifying threshold is not an out-of-distribution detector.

Evaluate macro precision/recall/F1, top-1/top-3, confusion matrix, per-class support and classifier latency. Record end-to-end extraction latency separately. The ALL checkpoint's unknown prior exposure prevents a clean signer-independent claim. No single-score comparison resolves this limitation.
