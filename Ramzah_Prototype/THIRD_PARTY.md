# Third-party assets and rights

This research prototype uses the following downloaded assets locally. Their presence in a ZIP or folder is **not** a grant for commercial, clinical or public redistribution.

| Asset | Source | Rights information verified for this project |
|---|---|---|
| KArSL videos and Arabic label workbook | [Official KArSL page](https://hamzah-luqman.github.io/KArSL/) | Public file access verified. An explicit redistribution/deployment license was not verified. Source videos are excluded from the ready-to-run ZIP. |
| SignBart KArSL-502 pretrained weights and source | [Hugging Face checkpoint](https://huggingface.co/tinh2312/SignBart-KArSL-ALL-502), [source repository](https://github.com/TinhNguyen2312/SignBart) | Public weight download verified. A clear redistribution/commercial grant was not verified. The small adapted checkpoint is included only for local research evaluation. |
| AraT5 MSA small | [Official checkpoint](https://huggingface.co/UBC-NLP/AraT5-msa-small) | Its model card says checkpoint use is exclusively for research and directs commercial users to contact the authors. The local fine-tuned checkpoint inherits this constraint. |
| MMS Arabic TTS | [Official checkpoint](https://huggingface.co/facebook/mms-tts-ara) | Model card lists CC BY-NC 4.0. Attribute the source and do not use commercially without appropriate permission. |
| MediaPipe Holistic task | [Google MediaPipe documentation](https://ai.google.dev/edge/mediapipe/solutions/vision/holistic_landmarker) | Official task asset downloaded for landmark extraction. Review the upstream asset notice for redistribution. |

The application has not been evaluated for medical safety or with Deaf Saudi Sign Language users. The generated messages are user-reviewed inquiries, not diagnoses or appointment confirmations.
